# PawSpot — векторные бренд-ассеты

Знак вручную отрисован кривыми Безье и простыми фигурами по утверждённому
референсу. Автотрассировка, растровые вставки и внешние ресурсы не используются.
Надпись PawSpot также состоит из контуров; шрифт устанавливать не нужно.

| Файл | Назначение |
| --- | --- |
| `pawspot-symbol.svg` | Основной знак, прозрачный холст 640 × 640 |
| `pawspot-logo.svg` | Вертикальная композиция со словом PawSpot, 830 × 750 |
| `pawspot-app-icon.svg` | Тот же знак на светло-зелёном скруглённом квадрате, 640 × 640 |
| `pawspot-symbol-small.svg` | Оптическая адаптация для 32–64 px |
| `pawspot-monochrome.svg` | Один цвет с прозрачными вырезами, 640 × 640 |

В основной версии, логотипе и иконке группа `symbol` содержит одинаковую
геометрию. Различаются только внешнее размещение и масштаб. Внутри знака
разделены группы `cat`, `dog`, `pin`, `paws`, `accents`; надпись — `wordmark`.
Палитра каждого SVG собрана в начале файла в `<style>`; префикс классов — `ps-`.

## Палитра

| Цвет | HEX |
| --- | --- |
| Зелёный: геометка, контуры, надпись | `#2C6B4E` |
| Оранжевый: следы лап | `#F5A34C` |
| Светло-зелёные акценты | `#98D2AC` |
| Овальная тень | `#B9E3C5` |
| Подложка иконки | `#DFF3E4` |
| Внутренняя часть ушей котика | `#C99B8E` |
| Мордочки и разделительный контур | `#FFFFFF` |

Цвета плоские, без градиентов, текстур и эффектов размытия. Основные контуры
согласованы между животными; черты лица используют более тонкие округлые линии.
Светло-зелёные акценты и овальная тень сохранены из референса. Слоган и подписи
презентации не входят в логотип.

## Маленькие размеры и PNG

В `pawspot-symbol-small.svg` сохранены положение животных, силуэты геометки
и следов. Убрана внутренняя окраска ушей котика, сохранены три линии усов.
Усилены внешние контуры и линии мордочек. На 32 px мелкие черты
неизбежно теряют детализацию; для крупного отображения используйте основной SVG.

PNG в `png/` имеют прозрачный фон и точные размеры:

- `pawspot-symbol-1024.png` — из основного знака;
- `pawspot-symbol-512.png` — из основного знака;
- `pawspot-symbol-256.png` — из основного знака;
- `pawspot-symbol-64.png` — из small-версии;
- `pawspot-symbol-32.png` — из small-версии.

## Монохром и использование

Монохромный SVG использует один видимый цвет `#2C6B4E` и составной `path`
с `fill-rule="evenodd"`. Исходные фигуры объединены и вычтены векторными
операциями; обводки переведены в контуры с сохранением формы. Мордочки,
разделительный контур и следы лап — настоящие прозрачные вырезы. Масок,
растровых вставок и белых подложек нет; поддержка luminance-mask не требуется.
Для перекраски меняйте только `ps-green-fill`.

SVG автономны и подходят для `<img src="…">`, браузера и импорта в векторный
редактор с поддержкой SVG-контуров. При многократной вставке исходного SVG inline
в один документ задавайте уникальные префиксы ID и обновляйте `aria-labelledby`;
при использовании через `<img>` это не требуется.
